# Quantum Code Technologies

Production portfolio platform for **Gackstone Baraka** — Senior Software Engineer & Full-Stack Systems & AI Architect.

Live at [gacksdev.vercel.app](https://gacksdev.vercel.app/)

## Stack

- **Framework:** Next.js 15 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS 4
- **Deployment:** Vercel

## Features

- 12-project portfolio with case studies, architecture diagrams, and comparison matrices
- Grounded AI Copilot (query engine over portfolio data)
- Technology Radar
- Global canvas dot-field background with per-dot independent motion
- Ambient blue glow drift animation
- Typing text animation system
- Light design system with strict zero-gradient policy
- Rate limiting and input sanitization
- WhatsApp contact integration

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Environment Variables

Copy `.env.example` to `.env.local` and fill in any optional secrets. See the file for details.

## Tests

```bash
npm test
```
